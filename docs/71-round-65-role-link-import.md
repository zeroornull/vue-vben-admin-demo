# 71 · 第 65 轮：角色 / 外链 CSV 导入

日期：2026-08-20。

这一轮打包两件边角。用户和部门能导入了，角色和外链跟上。操作日志仍不导入：那是系统记的流水，没有新建弹窗，也不该从文件灌进去。

## 本轮结论

角色页、外链页加了「导入」。只收导出时那份 UTF-8 CSV。表头必须对上。创建时间丢掉。菜单和操作按**中文标签**反查（`用户、部门`，`用户：编辑/删除`），不是编码。`无` 就是空勾选。

导入是写操作：按钮走 `role:create` / `link:create`，每一行再走原来的表单校验，再 POST。能进新建弹窗的才能进文件。不新开 `*:import`。不上 xlsx。不是事务。一次最多 100 条。

编码占用 `admin` / `user`、或和外链保留路由撞车，直接跳过。登录页 Form、页签右键、改密仍不做。

## 学习笔记

- 导出写中文，导入就必须能反查。操作名「新建」会在多张表重复，所以文件里是「用户：新建」，不能只认第二个字。
- 勾了操作会自动带上对应菜单。文件里菜单列是空的、操作列有「用户：编辑」，保存后用户菜单仍会在。和弹窗同一条路。
- 操作日志看起来也是一张表，但它没有「新建」。能导出去给人看，灌回来会冒充系统流水。
