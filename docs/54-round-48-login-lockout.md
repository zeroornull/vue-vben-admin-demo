# 54 · 第 48 轮：登录失败锁定

日期：2026-08-20。

## 本轮结论

同一账号连续输错密码 3 次，锁 1 分钟。锁定期内就算密码对了也不放行。成功登录清零。只挡 `POST /auth/login`，锁屏解锁、已登录会话都不算。

失败次数记在 Vite 进程里，刷新页面还在，重启 `bun run dev` 清掉。这和第 46 轮闲置锁屏不是一回事：闲置是登录之后没活动，这里是还没登录就打门。登录页 Form、页签右键、改密仍不做。

## 怎么验收

```bash
bun run dev
```

1. 退出登录。用户名 `vben`，密码乱填，提交两次：提示还可试 1 次
2. 再错一次：提示锁定，倒计时秒数
3. 立刻改回 `123456` 仍进不去
4. 等约 1 分钟，或重启 dev，再登可以进去
5. 登录后用户菜单「锁定屏幕」，密码输错不会把登录也锁掉

## 学习笔记

- 锁定判断在密码核对之前。否则锁定期还能靠「对/错耗时」猜密码。
- 未知用户名也计数。否则可以用「会不会锁」判断账号在不在。
- 1 分钟是给本机演示用的。真系统常更长，还要配验证码或二次确认。
- 解锁屏是另一条接口。已经证明你持有 token，失败不该连坐到登录锁。
